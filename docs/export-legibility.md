# Text size in the exported figure

Generated programs assess the **written PNG/SVG/PDF files**, then check text at
the requested manuscript width. `bbox_inches="tight"`, padding, titles and external
artists can change a file's physical width independently of `figsize`.

A measured negative control passed the old nominal check: a 3.4-inch canvas had
a 6-point external label, but its tight PNG was 6.9594 inches wide. Fitting that
file into a 3.4-inch column shrinks the label to about 2.9313 points. The new
check reports `text_too_small`; it keeps the files for review and strict mode
rejects the render. Conversely, a tightly cropped large canvas can have readable
text even when a calculation based on its unused canvas width would fail.

## Measurement and evidence

PNG uses pixel width and its physical horizontal DPI; missing DPI is unknown.
SVG uses absolute physical width units (pt, in, cm or mm). PDF uses the single
page's MediaBox width. These readers target the static files generated by the
tool, not arbitrary document layout or browser CSS. Relative/invalid dimensions,
corrupt files, unsupported formats and empty evidence produce
`export_size_unavailable`, never an assumed width or a clean font check.

When several static formats are requested, the widest measured file determines
the conservative text scale:

```text
scale = min(target manuscript width / widest exported width, 1)
effective text size = declared font size × scale
```

The scale never gives credit for enlarging a small file. `inspection.measurements`
records `basis`, `nominal_width_in`, per-path `widths_in`, `target_width_in`,
`evaluated_width_in` and `text_scale`. Unknown evaluated width/scale remain null.
The report schema adds this evidence without invalidating older version-1 reports;
an older report without measurements does not establish final-export legibility.
Regenerate existing programs to request the new check. An outdated installed
inspector produces incomplete required inspection rather than a nominal fallback.

The default internal floor is 5 points; configured venue presets can raise it.
A 1e-12 floating-point comparison tolerance avoids representation noise at an
exact boundary; a genuinely smaller value is not rounded into acceptance. These
are engineering checks, not a guarantee of publisher compliance or readability
for every reader. Uniform fitting into the requested width is assumed. Subsequent
document crops, CSS, font substitution or nonuniform scaling need another check.

## Inspecting your own figure

```python
from graphunslopify import inspect_figure

fig.savefig("figure.pdf", bbox_inches="tight")
report = inspect_figure(fig, target_width_in=3.4, export_paths=["figure.pdf"])
print(report.measurements)
```

Without `export_paths`, the API explicitly reports a `nominal` basis and keeps
the original canvas calculation. The caller must pair the figure with its actual
exports. Generated programs supply their recorded static outputs automatically,
including the table-image path. HTML responsiveness and supplementary animation
are separate contexts; this check makes no physical-width claim for them.

## Verification

`python/tests/test_exported_text_size.py` has 37 physical-size/API/runtime controls:
fixed widths, expanded/cropped files, multiple formats, absolute SVG units,
malformed/relative/missing dimensions, partial evidence, floor boundaries, actual
strict reports and outdated inspectors. The original 26 controls failed before
the feature existed; the direct 2.9313-point probe independently demonstrates
the missed legibility failure. Fresh-wheel smoke checks measured outputs and an
oversized-title negative control with external runtime connections blocked.

All 15 gallery figures pass with actual exported widths. Their widths can differ
from nominal without failing the font floor; a wider file alone is not an error.
The 15 baseline PNGs and four public reference illustrations retain identical
dimensions and pixels while their generated source/provenance is refreshed.
Visible table context and the full 21-kind scientific reference matrix remain
separate work.

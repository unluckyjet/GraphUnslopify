# Canonical figure runtime foundation

Current source centralizes 37 existing generated helpers in [`figure_runtime.py`](../../python/graphunslopify/figure_runtime.py). The emitter reads these same plain Python definitions through an AST-only build step. Maintainers change each helper once.

**Ordinary generated scripts remain inline in this milestone.** Default compact scripts, a complete standalone bundle, full runtime provenance and measured entry/runtime/bundle/startup acceptance are the remaining work in roadmap item 86. Published PyPI 0.8.0 predates this source feature; no release is implied.

## State and compatibility

The low-level `bind` API installs the canonical function code into each generated program's original globals dictionary. Programs retain separate reports, data, constants and defaults. Actual ABI, helper source SHA-256, required functions and source drift are checked before that dictionary changes. Nominal package version alone is insufficient.

The environment helper takes its optional-package list from each program. This preserves Excel reader provenance without rewriting a second helper implementation. Existing strict verification and original negative results remain mandatory.

After editing the canonical Python, run `PYTHON=/path/to/python npm run build:translator` and commit the refreshed helper text and translator. Python is required for this source build step; ordinary translation uses the committed Node bundle.

## Evidence and limits

[Actual controls and retained files](../../benchmarks/runtime/results/foundation-v1/README.md) cover 30 variants across all 21 chart types. Source Python 3.12, minimum Python 3.10 and a fresh wheel each pass original-script, bound-helper and current-inline comparisons: 90 actual strict executions per environment, retaining 29 passes and one original strict failure per path. Each program/output fingerprint is checked before the expected script-digest difference is normalized. Comparisons require actual PNG pixels, SVG drawing XML, PDF drawing streams, report/environment/policy and text agreement.

The [accepted baseline](../../benchmarks/runtime/protocol.json) was frozen before helper changes and retains all actual runtime files, inputs, scripts and original outcomes. Its seven-repeat `compile()` profile measures only warm in-memory compilation, not imports, execution or rendering. No speed or human productivity benefit is established by this foundation.

The published examples and seven reference illustrations retain their original pixels and data. Runtime source fingerprints change when source changes; their refreshed metadata continues to bind actual generated bytes. No benchmark evaluator or scientific reference value was weakened.

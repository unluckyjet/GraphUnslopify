## Required behavior

   criticize about these figures?” for actual selected figures. Reuse the existing

   separately from clearly labelled,unverified qualitative model suggestions.
   Failed,missing,stale,unrun and PDF visual-only evidence must remain distinct.
   Neither valid model JSON nor a cited evidence ID certifies an interpretation.

   No automatic raw dataset,image,script or full local environment transmission.
   Keep credentials out of disclosures/downloads. No silent model requests.

   returning. Reject missing/unknown figure keys,citations,mutation fields and
   malformed/oversized replies. Prevent duplicate/late requests from replacing
   newer context. Retain provider failures without borrowing a previous success.
5. Deliver usable shared Python/CLI and actual editor/paper-review workflows:
   selected figures,question,provider configuration,disclosure,consent,readable
   separated findings/advice,download,cancel and stale-result handling. Model
   advice does not apply scientific or presentation changes.
6. Exercise real saved positive/failed claims,unavailable/historical/PDF states,
   source/export/context races,privacy,provider errors and bounded lifecycle.
   Include actual configured inference using retained local tools;controlled
   HTTP proves contracts,not model quality or independent scientific judgment.
7. Current/minimum/cleanly installed package and actual browser/native evidence,
   all required local gates,normal coherent pushes and exact14 CI must pass.
   Preserve original graphics and frozen research results;no new release/tag.

Work with your data

Use local CSV, JSON or Parquet. The Python CLI, notebook API and local editor run on your machine. An agent can also request generated code through MCP.

Inspect the evidence

Check declared comparisons, available uncertainty, rendered geometry and readability. Keep reports, generated programs and provenance alongside PNG, SVG and PDF exports.

Review a whole project

Regenerate a paper's figure manifest, compare changes with a previous audit, and run the checks in GitHub Actions before accepting an update.

Start locally

Python 3.10 or newer, in a virtual environment. This pinned release includes the local translator and its runtime; no npm setup or server is needed.

python -m pip install "https://github.com/unluckyjet/GraphUnslopify/releases/download/v0.7.0/graphunslopify-0.7.0-py3-none-any.whl"
graphunslopify doctor
graphunslopify demo

The demo creates a dataset, specification, Python program, verified static exports and report. Then try graphunslopify preview for the local editor, or follow the installation guide to use your own data.

Current development rejects failed or incomplete verification by default. The pinned 0.7.0 release requires --strict on render/run/check and strict=True in the Python SDK; its demo and paper audit are already strict.

What the evidence establishes

Static rules and local runtime checks cover supported computations and presentation conditions. They cannot establish where data came from, experimental independence, causal validity or the truth of an undeclared claim.

The numerical reference matrix and three-workflow pilot document the engineering evidence. External researcher testing and independent scientific benchmarking remain outstanding.

Connect an agent or service

Use graphunslopify mcp with the optional agent extra for local stdio. The existing hosted API also supports HTTP translation and MCP. Remote translation sends your specification or profile to the service; generated Python reads your data locally.

# Independent scientific references

Create a compact, documented reference matrix for all 21 kinds, reusing actual independent
known-answer evidence where it already exists. Fill scientific/derived gaps with public synthetic
fixtures whose expected quantities are computed independently of the emitter implementation.
Inspect actual artists/tables/descriptions and exported values, not just generated substrings.

Kaplan–Meier ties/domains/tails/descriptions/claim inputs now have independent hand/SciPy artist
references and failure controls (spec 26). Calibration probabilities/outcomes, binned ECE,
descriptions/claims, precision and panel-specific legends now have independent hand/artist/oracle
references and failure controls (spec 27). Paired differences now share unit matching, explicit
exclusions, mean/interval/descriptions and scoped runtime evidence with independent hand/SciPy
artist references and failure controls (spec 28). Q-Q normal/uniform coordinates and population-
quartile lines, sample/domain guards and derived/scoped evidence now have hand/SciPy artist
references and failure controls (spec 29). Scaling log-space parameters, conditional t95/explicit
point-only/unknown intervals, retained domains, actual curves, descriptions and scoped records now
have independent hand/SciPy artist/runtime references (spec 30). Shared identifier spelling,
raw typed filters, unit/group/category consistency, ordering and one-snapshot provenance now have
62 independent actual-artist/runtime controls (spec 31). Reuse that evidence. Cell annotation contrast now has34 independent artist/math/normalization/alpha/raster/inspector/
runtime/provenance controls and522 actual offline browser labels (spec32). Prioritize categorical
overlay geometry and final exported-width/table context, then complete the per-kind coverage map
for the full inventory. Invalid domains/missing IDs must not become plausible clean figures;
state or enforce supported behavior and account for omitted/unmatched observations. Preserve
leading-zero category identities and numeric group/order/claim consistency where supported.
Overlays must align with actual categorical positions, or refuse unsupported combinations.

Review generated descriptions and disclosure against what the tool can establish. The concrete
unknown-origin disclosure and literal LaTeX export defects are resolved in spec 25; reuse its actual
compiled-text evidence. Measure final exported
width when evaluating text legibility; improve any confirmed misleading table/context behavior.
Split a coherent discovered defect into a small verified milestone when needed, preserving this
contract until its matrix and known gaps are actually addressed.

## Acceptance evidence

- Independent values/references and documented dataset/domain assumptions cover supported kinds.
- Wrong/unknown results and unsupported semantic combinations cannot masquerade as verification.
- Real regressions assert numerical values, identity, accounting, descriptions and rendered context.
- Public validation documentation distinguishes tested behavior from remaining scientific limits.
- Required local gates pass, relevant gallery artifacts are reviewed, Obsidian is corrected, and
  both GitHub CI workflows are checked after each small push.

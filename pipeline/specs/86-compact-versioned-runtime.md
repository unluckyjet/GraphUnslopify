# 86 — Compact versioned runtime

Depends on complete85 and its exact CI acceptance. No release is implied.

## Acceptance

1. Reuse actual versioned runtime functions so ordinary generated scripts become
   smaller and readable. Keep one canonical scientific implementation; do not
   replace lines with an opaque compressed program or silently fork mathematics.
2. Bind actual runtime capabilities/source/ABI; a shared nominal package version
   must not accept an older incompatible installation. Give actionable refusal.
3. Export a genuinely standalone bundle containing the required actual runtime,
   provenance/licenses and explicit third-party requirements. It must reproduce
   outside the checkout without relying on an unpublished local helper module.
4. Preserve all21 kinds, identifiers, units, seeded uncertainty, supported claims,
   native checks, literal text, requested formats and current geometry. Maintain
   original independent-reference/NIST protocols and retain negative outcomes.
5. Measure actual entry/runtime/bundle bytes and lines, startup/execution costs
   and comparison conditions; report regressions or no benefit without hiding it.
6. Demonstrate source/minimum/fresh, missing/wrong runtime and genuine bundled
   reproduction. Run required baselines/references/gallery when emission/layout
   changes; seven checks/push/exact all-nine/Figure per milestone. Update Obsidian.

# Preview saved figures on pages and slides

Open `graphunslopify project-preview PAPER`. In **Saved runs & changes**,
select an audit and figure, then open **Presentation preview**.

- **Single column** places the figure in an 85 mm column on an A4 sample page.
- **Double column** gives the figure up to 178 mm across the sample page.
- **Widescreen slide** centers the figure in the content area of a 16:9 slide.

A tall figure scales uniformly to fit the available height. The preview shows
the resulting physical width and height. The sample page fits the browser
window and provides visual context for the placement. It uses placeholder
surrounding text. Journal requirements are checked separately.

The preview uses a verified saved export from the selected audit. When local
PDF support is available it uses the saved PDF and scales any measured
extractable text sizes to the placement. A PNG preview reports its effective
raster resolution. Physical text size is shown as unavailable when the export
has no usable text measurements. The saved image bytes, project settings and
audit verdict remain intact.

GraphUnslopify 0.7.0 turns semantic JSON figure specifications into local Python figures with recoverable provenance and strict verification reports.

- All 21 figure kinds have documented independent core numerical/domain references. Unknown uncertainty, unsupported semantics and failed checks remain explicit.
- Installable local translator/runtime, a reproducible demo, notebook and Python builder, local agent tools and browser editor.
- Manifest-driven paper audits, figure/data/claim change reports and reusable Figure CI.

Install with Python 3.10+ in a virtual environment:

```sh
python -m pip install "https://github.com/unluckyjet/GraphUnslopify/releases/download/v0.7.0/graphunslopify-0.7.0-py3-none-any.whl"
graphunslopify doctor
graphunslopify demo
```

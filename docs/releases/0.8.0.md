# GraphUnslopify 0.8.0

This release makes strict verification the default and adds local review packets
for ordinary manuscript PDFs. It includes the existing 21 figure kinds,25 recipes,
local Python/CLI/editor/notebook/agent workflows and source-linked paper audits.

- Failed or incomplete required checks reject execution by default in generated
  scripts, CLI and SDK. Explicit `--no-strict` / `strict=False` retains actual
  verdicts while opting out of rejection. Warning rejection always implies strict.
- `graphunslopify audit-pdf` with the optional `[pdf]` renderer produces offline
  page/text/manual-crop evidence. Unavailable data/claim checks stay incomplete;
  `--prepare-only` changes the preparation exit policy, not scientific verification.
- Public penguin/Iris examples compare actual artists and seeded faults with
  separate calculations. They are author-run descriptive examples, not full paper
  replication or independent researcher/adoption evidence. Volunteers are deferred.
- The product homepage and repository metadata now describe the current workflows.
  Versioned release verification and PyPI Trusted Publishing use the same tested
  wheel/source files. The0.7.0 release remains unchanged.

Published on PyPI and GitHub; both distribution hashes match. A genuine fresh registry
install and a downloaded-source rebuild were verified. See [publication evidence](0.8.0-publication.json).

Install the fixed PyPI version:

```sh
python -m pip install graphunslopify==0.8.0
graphunslopify doctor
graphunslopify demo
```
